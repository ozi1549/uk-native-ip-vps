## 原生 IP、住宅 IP、双 ISP，价差买的是哪一层

原生 IP 说的是归属地。IP 段注册在英国，whois 查出来属于英国运营商的地址段，并非从别处转租的美国或香港段。这一层解决的是“平台认不认你在英国”。

住宅 IP 说的是来源类型。IP 挂在 Virgin Media、Sky、BT 这类家庭宽带运营商名下，风控看到的是“英国某户人家在上网”。机房 IP 的 ASN 一查就是云厂商，平台的识别成本几乎为零。

双 ISP 再进一步，IP 的注册信息和路由归属分别落在两家英国本土 ISP 上，被标成可疑代理的概率比单一 ISP 低。

价格差就是这么来的。同样一台 1 核 512MB 的机器，挂机房 IP 卖几美元，挂原生 IP 十几美元，挂住宅属性再往上加。WePC 英国线标的是“英国原生家宽 IPv4”，页面没有写双 ISP；同站的日本、韩国几个套餐页面写了双 ISP，英国这两档没写，按页面表述理解就行。

**这里有个必须说清的事实**。一份第三方测评对 WePC 英国住宅套餐（产品 ID 209）做了 IP 属性检测，多个数据库给出的结论是「英国原生、商业属性、非住宅」。标着“家宽”的机器，检测工具不一定认它是住宅 IP。同一个测评里，这台机器能解锁英国 TikTok、ChatGPT、Claude、Netflix、Disney+，Gemini 不行；CPU 是 Xeon Gold 6138，KVM 虚拟化，机房在伦敦，上游为 ZGX US LLC，I/O 约 194MB/s，性能评分偏低。

这不代表它没法用，只说明“原生”和“住宅”在检测层面是两回事。拿到机器后自己查一遍更稳：用 whoer.net 或 scamalytics 看 ASN 和欺诈值，ASN 落在 Sky、BT、Virgin Media 这类英国家庭宽带运营商段里才算住宅；落在机房段，那就是一台原生机房 IP。

## 三条硬限制：线路、系统、退款

**线路不是大陆优化。** WePC 英国走的是纯国际路由，测评提到部分路由绕经美国，延迟偏高，官方定位也建议配合中转发使用。想直连舒服，得自己在香港或日本加一个中转节点，这部分成本和时间要算进去。开 BBR 是基本操作，对国际线路的吞吐提升明显，几条命令的事。

同理，实时交互场景别指望它。SSH 敲命令、远程桌面会明显发涩；养号、发内容、解锁流媒体这类不需要即时响应的活儿，200ms 以上的延迟不影响结果。
